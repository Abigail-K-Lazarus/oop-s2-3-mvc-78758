# oop-s2-3-mvc-78758
Acme Global College Management System
A comprehensive web based student and course management system for Acme Global College's three branches in Ireland.

Features
-Role-Based Access Control (Admin, Faculty, Student) -Student Registration & Enrolment -Course Management -Attendance Tracking -Gradebook Management -Exam Results with Release Control -Faculty Access to Student Contact Details -Multi-Branch Support (Dublin, Cork, Galway)

Technology Stack
ASP.NET Core MVC 8.0
Entity Framework Core 8.0
SQL Server LocalDB
ASP.NET Core Identity
xUnit for Testing
Bootstrap 5
GitHub Actions CI/CD
Prerequisites
Visual Studio 2022 or later
.NET 8.0 SDK
SQL Server LocalDB (comes with Visual Studio)
